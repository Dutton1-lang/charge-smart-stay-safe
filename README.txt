CHARGE SMART STAY SAFE WEBSITE
================================

This folder contains the full website.

FILES
-----
index.html  - the page content
style.css   - all colours, layout and mobile styling
script.js   - the mobile menu
assets/     - the three original graphics supplied by you

HOW TO PUT IT ON GITHUB
-----------------------
1. Open your charge-smart-stay-safe repository.
2. Delete or replace the old index.html and style.css files.
3. Upload index.html, style.css and script.js.
4. Upload the complete assets folder.
5. Commit the changes.
6. Wait one or two minutes and refresh your GitHub Pages website.

IMPORTANT
---------
Do not rename the graphics inside the assets folder unless you also update
their names in index.html.

The three supplied graphics have been copied into the project unchanged.
