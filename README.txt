CHARGE SMART STAY SAFE WEBSITE

This folder contains a complete single-page website prototype.

FILES
- index.html: webpage content
- style.css: design and layout
- script.js: mobile menu
- images/charge-smart-stay-safe.jpg: used as both the campaign logo and hero banner
- images/website-qr-code.png: QR code to the live GitHub Pages website
- downloads/: prototype downloadable resources

HOW TO UPLOAD TO GITHUB
1. Open your charge-smart-stay-safe repository.
2. Tap Add file, then Upload files.
3. Upload the CONTENTS of this folder, not the outer folder itself.
4. Make sure index.html is at the top level of the repository.
5. Commit the changes.
6. Wait one or two minutes and refresh:
   https://dutton1-lang.github.io/charge-smart-stay-safe/

IMPORTANT
This is an interview presentation prototype and not an official Cheshire Fire & Rescue Service webpage.
